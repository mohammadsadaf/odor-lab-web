Two paths through the same question

The app runs the same trained baseline directly in your browser: radius-2 Morgan fingerprints (2,048 bits) and one logistic regression classifier per odor word. It supports arbitrary valid single-molecule SMILES.

The Python project’s OpenPOM notebook trains the separate graph neural network: five message-passing steps, a 256-dimensional embedding, and 138 odor outputs. It requires a compatible Linux GPU environment. The app’s scores and metrics come from the baseline, not OpenPOM.

How the evaluation works

Canonical duplicates are merged before an iterative multilabel 80/10/10 split. Test molecules are never used for fitting. Rare labels without both classes in a split are excluded from macro ROC-AUC and listed in the report. This is a random molecular split; related structures may occur across splits.

ROC-AUC measures ranking: 0.5 is chance and 1.0 is perfect. It does not establish probability calibration, intensity, or performance on unfamiliar chemistry.

OPTIONAL HARDWARE EXPERIMENT

Give your project a nose.

A separate classifier for recordings from a BME688 sensor. Training runs in the downloadable Python project.

HARDWARE REQUIRED

Record. Label. Train.

Collect real gas resistance readings at ten heater steps for each smell. Record multiple sessions on different days, including plain air. Use one row per complete ten-step cycle.

session,label,r0,r1,r2,r3,r4,r5,r6,r7,r8,r9
coffee-day1,coffee,12000,11800,…
air-day1,air,22000,21000,…

Each r column is resistance in ohms. The abbreviated example above illustrates the schema; supply ten real numeric readings in every row.

Train from your recordings

python -m scripts.train_sensor recordings.csv

The Python project’s script holds out entire sessions, fits an Extra Trees classifier to log resistance, and exports accuracy, a confusion matrix, and a model artifact. Every label must appear in at least three distinct sessions.

This model only recognizes the classes you record. It has no connection to the molecular predictor and cannot identify arbitrary new smells.
